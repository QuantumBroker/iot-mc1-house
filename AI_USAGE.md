## Журнал використання
1. Етап: Створення симулятора пристроїв
   - Мета: Створити скрипт на Python для генерації телеметрії сенсорів (геркон, дим, рух).
   - Промпт: "Напиши Python скрипт для MQTT клієнта paho-mqtt під Варіант 3 з обробкою Last Will."
   - Що взято: Каркас підключення paho-mqtt та структуру виведення JSON-повідомлень.
   - Що змінено: Переведено підключення на тестовий публічний брокер test.mosquitto.org.
